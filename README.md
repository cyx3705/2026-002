# 2026-002-陪伴智能小车

> 陪伴智能小车三维设计资料，包含 Siemens NX 整车装配与零件、Solid Edge 装配体，以及底盘架 Parasolid 交换文件

## 项目内容

1. **b-Module-NX**
Siemens NX 三维模型：整车装配 `小车装配.prt`，以及底盘架、架子、前部、缓震架子、轮、屏幕、电源开关、电池、电机、充电口、超声波遮挡、U 型支架、中控存放板件、外壳、超声波雷达、尾翼等零件；根目录另有对应压缩包 `b-Module-NX.7z`。
2. **b-Module-SE**

- 装配体：`0-装配体.asm`（含 `0-装配体.cfg`）；
- 零件：`零件.par`。

3. **b-Module-GE**

- 底盘架 Parasolid 交换文件：`1100-底盘架.x_t`。
